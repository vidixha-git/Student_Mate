# STUDENT-MATE — Project Statement

## 1. Problem Statement

Managing student information manually can be time-consuming and difficult when the number of students increases. Maintaining student details such as student ID, name, course, marks, and attendance in notebooks or separate files can also lead to errors and difficulty in searching or updating records.

The purpose of STUDENT-MATE is to develop a simple Java-based Student Management System that allows users to manage student records through a command-line interface.

The system provides basic operations such as adding, viewing, searching, updating, and deleting student records. It also calculates grades based on student marks and demonstrates file handling for storing student information.

---

## 2. Project Scope

The scope of the project includes:

* Creating student records.
* Storing student ID, name, course, marks, and attendance.
* Displaying student records.
* Searching students using Student ID.
* Updating student information.
* Deleting student records.
* Calculating student grades.
* Saving student data in a text file.
* Loading stored student data.
* Handling invalid user inputs.
* Demonstrating Java exception handling.

---

## 3. Project Objectives

The main objectives of the project are:

1. To develop a simple Student Management System using Java.
2. To understand and implement Object-Oriented Programming.
3. To use classes and objects for representing student information.
4. To implement encapsulation using private data members and getters/setters.
5. To use ArrayList for storing multiple student records.
6. To implement a menu-driven command-line interface.
7. To calculate student grades using conditional statements.
8. To implement file handling for data storage.
9. To handle invalid inputs using exception handling.
10. To develop a simple and maintainable Java application.

---

## 4. Functional Requirements

The system should provide the following functions:

### 4.1 Add Student

The user should be able to enter:

* Student ID
* Student Name
* Course
* Marks
* Attendance

The system should create and store the student record.

### 4.2 View Students

The system should display the details of all students currently stored in the application.

### 4.3 Search Student

The user should be able to enter a Student ID and search for the corresponding student record.

### 4.4 Update Student

The user should be able to modify:

* Name
* Course
* Marks
* Attendance

### 4.5 Delete Student

The user should be able to delete a student record using the Student ID.

### 4.6 Grade Calculation

The system should calculate the grade automatically based on marks.

### 4.7 File Storage

Student information should be stored in a text file so that records can be maintained outside the running program.

---

## 5. Non-Functional Requirements

### Performance

The system should perform basic student operations efficiently for normal-sized datasets.

### Usability

The application should provide simple instructions and menu options that are easy to understand.

### Reliability

The system should handle invalid inputs and unexpected conditions without terminating unnecessarily.

### Maintainability

The application should use separate classes for different responsibilities to make the code easier to understand and modify.

### Portability

The application should run on any system that has a compatible Java Development Kit installed.
